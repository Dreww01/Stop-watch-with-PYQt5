### 📁 Project Structure

```
stopwatch_project/
├── main.py         # App entry point
├── gui.py          # Handles the GUI layout and button events
└── stopwatch.py    # Core stopwatch logic and time formatting
```

---

### 🚀 Features

✅ Start, stop, and reset stopwatch
✅ Real-time time display every 10 milliseconds
✅ Stylish dark-themed UI
✅ Separated logic, GUI, and entry-point for clean code

---

### 🧑‍💻 Technologies Used

* Python 3.x
* PyQt5

---

### 🛠️ Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/your-username/stopwatch-project.git
   cd stopwatch-project
   ```

2. **Install dependencies**

   ```bash
   pip install PyQt5
   ```

3. **Run the app**

   ```bash
   python main.py
   ```

---

### 📌 File Descriptions

| File           | Description                            |
| -------------- | -------------------------------------- |
| `main.py`      | App launcher using `QApplication`      |
| `gui.py`       | Contains all UI widgets and styling    |
| `stopwatch.py` | Handles stopwatch logic and formatting |
